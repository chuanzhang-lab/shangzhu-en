| 特征 | 判据 | 角色 |

| A 名称指纹 | `FINGERPRINT_RE`：xhr-task / 端到端（精确名）/ 测试任务 / probe-* / r2-test-* 等测试写入用名 | 定罪 |

不按指纹定罪——仅零消息时进清理候选，带对话一律豁免进待裁决。
（母版只有 A/B 两条；C 与默认名单列是 EN 版新增——`New task` 在 EN 产品里
就是默认名，误删风险定为高，见计划 6.3 / 风险表。）
